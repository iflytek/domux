# Contributing to iFLYTEK Open Source

Thank you for your interest in contributing to iFLYTEK Open Source projects! We welcome contributions from the community.

## How to Contribute

1. **Find an Issue**: Look for open issues in our repositories.
2. **Fork and Branch**: Fork the repository and create a new branch for your changes.
3. **Submit a Pull Request**: Once your changes are ready, submit a PR with a clear description of your work.

## Code of Conduct

Please follow our [Code of Conduct](https://github.com/iflytek/community/blob/master/code-of-conduct.md).

## More
For detailed contribution guidelines, please refer to our [Community Contributing Guide](https://github.com/iflytek/community/blob/master/CONTRIBUTING.md).
